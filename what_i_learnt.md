Building this API really showed me how to connect the dots in Django REST Framework. Setting up separate apps for the inventory and orders kept the structure clean, and getting the Product, Box, and Order models talking to each other through ViewSets and serializers made a lot of abstract concepts click.

The box recommendation algorithm was definitely the biggest challenge. At first, I was just checking basic dimensions, but I realized pretty quickly that I had to account for product rotation—a box might fit if you just turn the item sideways. Factoring that in alongside weight limits, leftover space, and cost turned into a pretty intense logic puzzle.

My biggest takeaway, though, was learning how to actually work with AI tools. The generated code gave me a head start, but I couldn't just copy and paste it. I had to write my own tests to catch edge cases the AI completely missed, like handling empty orders, dealing with database constraints if someone tries to delete a product already tied to an order, or figuring out what to do when no box actually fits. It proved to me that AI is great for scaffolding, but you still have to be the one steering the ship and verifying the logic.
