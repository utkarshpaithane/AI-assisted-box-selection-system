from rest_framework import serializers
from .models import Order, OrderItem
from inventory.models import Product
class OrderItemSerializer(serializers.ModelSerializer):
    # We only expect the user to provide the product ID and quantity
    product_id = serializers.PrimaryKeyRelatedField(
        queryset=Product.objects.all(), source='product'
    )
    class Meta:
        model = OrderItem
        fields = ['id', 'product_id', 'quantity']
class OrderSerializer(serializers.ModelSerializer):
    # 'items' must match the related_name we defined in our models.py!
    items = OrderItemSerializer(many=True)
    class Meta:
        model = Order
        fields = ['id', 'created_at', 'items']
    # We must override the create method to handle the nested items array
    def create(self, validated_data):
        items_data = validated_data.pop('items')
        order = Order.objects.create(**validated_data)
        
        for item_data in items_data:
            OrderItem.objects.create(order=order, **item_data)
            
        return order

Stage 4: Box Selection Algorithm (Explanation)
The prompt requires us to handle multiple products and their rotations, but also notes that full 3D bin-packing is overly complex. We need a "reasonable simplified packing strategy" and we must clearly document its assumptions.

Our Simplified Strategy: "The 1D Stacking Method"
Instead of complex 3D Tetris, we will assume that we are going to stack all products in the order on top of each other in a single column (a tower).

To make this tower as stable and compact as possible, we will lay every product flat on its largest face.

For every product, we sort its dimensions from largest to smallest: [Length, Width, Height].
Length is the longest side.
Width is the middle side.
Height is the shortest side.
We stack them up.
The total height of our stack will be the sum of all the individual shortest sides (sum(heights)).
The required length of our stack will be the maximum length among all the products (max(lengths)).
The required width of our stack will be the maximum width among all the products (max(widths)).
This creates a "Combined Bounding Box" for the entire order.
We then take this Combined Bounding Box and check if it can fit inside a shipping box, allowing for the combined box to be rotated in any of the 6 possible 3D orientations.
Example:

Product A (x1): 10 x 20 x 30 -> Sorted: [30, 20, 10]
Product B (x2): 5 x 15 x 15 -> Sorted: [15, 15, 5]
Stack Dimensions:
Max Length: max(30, 15, 15) = 30
Max Width: max(20, 15, 15) = 20
Total Height: 10 + 5 + 5 = 20 (Remember Product B has quantity 2)
Combined Bounding Box: 30 x 20 x 20
If we have a box that is 25 x 35 x 25, our stack fits! (Because 30x20x20 can rotate to fit inside 35x25x25).
Assumptions & Limitations to document later:

Assumption: Items are stacked in a single vertical column.
Limitation: This is not perfectly optimal. If we have a very wide box, we could theoretically put items side-by-side instead of stacking them. Our algorithm might reject a box that could technically fit the items if placed side-by-side. However, this is a safe, deterministic, and highly explainable simplification.
Selection Criteria
Once we find all boxes that can fit the dimensions and hold the total weight, how do we pick the best one? The assignment says: "Prefer avoiding unnecessary empty space and then consider cost".

We calculate the volume of each valid box.
We calculate the total volume of all products.
Empty space = Box Volume - Total Product Volume.
We will sort the valid boxes first by empty_space (ascending), and then by cost (ascending).
Let's Code It
We will create a separate service module for this logic, exactly as requested ("Create a separate service/module for box-selection logic").

Create a new file called services.py inside the orders app directory (orders/services.py) and paste the following code:

python

from typing import Optional, List, Tuple
from inventory.models import Box
class BoxRecommendationService:
    @staticmethod
    def get_sorted_dimensions(l: float, w: float, h: float) -> Tuple[float, float, float]:
        """Returns dimensions sorted from largest to smallest."""
        dims = sorted([l, w, h], reverse=True)
        return dims[0], dims[1], dims[2]
    @staticmethod
    def recommend_box(order_items) -> Tuple[Optional[Box], float, str, List[Box]]:
        """
        Recommends the best box for a list of order items.
        Returns: (Recommended Box, Total Weight, Reason, List of other valid boxes)
        """
        boxes = Box.objects.all()
        if not boxes.exists():
            return None, 0, "No boxes available in the system.", []
        total_weight = 0
        total_volume = 0
        
        # Dimensions for our 1D Stacking Strategy
        max_item_length = 0
        max_item_width = 0
        total_stack_height = 0
        # 1. Calculate the required stack dimensions and weight
        for item in order_items:
            product = item.product
            qty = item.quantity
            
            total_weight += (product.weight * qty)
            total_volume += (product.length * product.width * product.height * qty)
            
            # Sort product dimensions (Largest, Middle, Smallest)
            p_l, p_w, p_h = BoxRecommendationService.get_sorted_dimensions(
                product.length, product.width, product.height
            )
            
            if p_l > max_item_length:
                max_item_length = p_l
            if p_w > max_item_width:
                max_item_width = p_w
                
            # We stack along the shortest dimension
            total_stack_height += (p_h * qty)
        # The bounding box of our stacked items
        stack_dims = BoxRecommendationService.get_sorted_dimensions(
            max_item_length, max_item_width, total_stack_height
        )
        valid_boxes = []
        # 2. Filter boxes that can fit the stack and hold the weight
        for box in boxes:
            if total_weight > box.max_weight:
                continue
                
            box_dims = BoxRecommendationService.get_sorted_dimensions(
                box.internal_length, box.internal_width, box.internal_height
            )
            
            # Check if stack fits inside the box (comparing sorted dimensions handles all rotations!)
            if (stack_dims[0] <= box_dims[0] and 
                stack_dims[1] <= box_dims[1] and 
                stack_dims[2] <= box_dims[2]):
                
                box_volume = box.internal_length * box.internal_width * box.internal_height
                empty_space = box_volume - total_volume
                
                valid_boxes.append({
                    'box': box,
                    'empty_space': empty_space,
                    'cost': box.cost
                })
        if not valid_boxes:
            return None, total_weight, "Order exceeds dimensions or weight capacity of all available boxes.", []
        # 3. Sort by empty space (ascending), then by cost (ascending)
        valid_boxes.sort(key=lambda x: (x['empty_space'], x['cost']))
        best_match = valid_boxes[0]['box']
        other_valid_boxes = [item['box'] for item in valid_boxes[1:]]
        reason = (f"Selected for minimizing empty space ({round(valid_boxes[0]['empty_space'], 2)} cubic units). "
                  f"Total order weight is {round(total_weight, 2)}.")
        return best_match, total_weight, reason, other_valid_boxes

python

import itertools
from typing import Optional, List, Tuple, Set
from inventory.models import Box
class BoxRecommendationService:
    """
    Service for determining the most suitable shipping box for an order.
    
    Assumptions & Limitations:
    - Products are stacked vertically in a single column.
    - Each product is placed on its largest face (largest dim = length, middle = width, smallest = height).
    - Products are not arranged side-by-side.
    - This is a simplified packing strategy, not a full 3D bin-packing algorithm.
    - The algorithm may reject a box that could accommodate the products using a more efficient arrangement.
    - The algorithm is deterministic and easy to explain and test.
    - The unused_space value is a bounding-box-based heuristic, not an exact measurement of physical empty space.
    """
    @staticmethod
    def get_sorted_dimensions(l: float, w: float, h: float) -> Tuple[float, float, float]:
        """Returns dimensions sorted from largest to smallest (Length, Width, Height)."""
        dims = sorted([l, w, h], reverse=True)
        return dims[0], dims[1], dims[2]
    @staticmethod
    def calculate_combined_dimensions(order_items) -> Tuple[float, float, float]:
        """
        Calculates the Combined Bounding Box for the order using the 1D Stacking Method.
        Returns: (required_length, required_width, required_height)
        """
        max_length = 0.0
        max_width = 0.0
        total_height = 0.0
        for item in order_items:
            product = item.product
            qty = item.quantity
            
            # Largest dimension becomes base length, middle is base width, smallest is stacking height
            pl, pw, ph = BoxRecommendationService.get_sorted_dimensions(
                product.length, product.width, product.height
            )
            
            if pl > max_length:
                max_length = pl
            if pw > max_width:
                max_width = pw
                
            total_height += (ph * qty)
        return (max_length, max_width, total_height)
    @staticmethod
    def calculate_total_weight(order_items) -> float:
        """Calculates the total weight of all items in the order."""
        total_weight = 0.0
        for item in order_items:
            total_weight += (item.product.weight * item.quantity)
        return total_weight
    @staticmethod
    def get_unique_orientations(l: float, w: float, h: float) -> Set[Tuple[float, float, float]]:
        """Generates all unique 3D permutations of the given dimensions."""
        return set(itertools.permutations([l, w, h]))
    @staticmethod
    def dimensions_fit(combined_dims: Tuple[float, float, float], box: Box) -> bool:
        """
        Checks if the Combined Bounding Box fits inside the shipping box.
        Tests all unique orientations of the bounding box.
        """
        req_l, req_w, req_h = combined_dims
        unique_orientations = BoxRecommendationService.get_unique_orientations(req_l, req_w, req_h)
        
        for orientation in unique_orientations:
            o_l, o_w, o_h = orientation
            if (o_l <= box.internal_length and 
                o_w <= box.internal_width and 
                o_h <= box.internal_height):
                return True
                
        return False
    @staticmethod
    def calculate_unused_space(combined_dims: Tuple[float, float, float], box: Box) -> float:
        """
        Calculates unused space based on the Combined Bounding Box volume.
        This is a heuristic for selecting a compact box, not exact physical empty space.
        """
        box_volume = box.internal_length * box.internal_width * box.internal_height
        req_volume = combined_dims[0] * combined_dims[1] * combined_dims[2]
        return box_volume - req_volume
    @staticmethod
    def recommend_box(order_items) -> Tuple[Optional[Box], float, str, List[Box]]:
        """
        Filters boxes based on weight and dimensions, then sorts valid boxes 
        by unused space (ascending) and cost (ascending).
        
        Returns: (Recommended Box, Total Weight, Reason String, List of other valid boxes)
        """
        boxes = Box.objects.all()
        if not boxes.exists():
            return None, 0.0, "No boxes available in the system.", []
        total_weight = BoxRecommendationService.calculate_total_weight(order_items)
        combined_dims = BoxRecommendationService.calculate_combined_dimensions(order_items)
        valid_boxes = []
        for box in boxes:
            # 1. Weight Check
            if total_weight > box.max_weight:
                continue
                
            # 2. Dimension Check
            if not BoxRecommendationService.dimensions_fit(combined_dims, box):
                continue
                
            # Both checks passed
            unused_space = BoxRecommendationService.calculate_unused_space(combined_dims, box)
            
            valid_boxes.append({
                'box': box,
                'unused_space': unused_space,
                'cost': box.cost
            })
        if not valid_boxes:
            return None, total_weight, "Order exceeds dimensions or weight capacity of all available boxes.", []
        # Sort by: 1. unused_space (ascending), 2. cost (ascending)
        valid_boxes.sort(key=lambda x: (x['unused_space'], x['cost']))
        best_match = valid_boxes[0]['box']
        other_valid_boxes = [item['box'] for item in valid_boxes[1:]]
        unused_val = round(valid_boxes[0]['unused_space'], 2)
        reason = (f"Selected box with lowest bounding-box unused space ({unused_val} cubic units) "
                  f"and lowest cost. Total order weight is {round(total_weight, 2)}.")
        return best_match, total_weight, reason, other_valid_boxes
Explanation of the Code
We rely heavily on Python's itertools.permutations. Wrapping it in set() automatically removes any duplicate combinations (which happens if a box is a cube, e.g., 20x20x20).
The functions are entirely isolated. This means we can write very clean Unit Tests later where we pass a fake tuple of dimensions to dimensions_fit() without needing a real database connection!
The algorithm perfectly adheres to your flow: it never modifies individual product orientations after they are added to the bounding box.

Box-Selection Algorithm
The system uses a custom 1D Stacking Method to evaluate bounding boxes, avoiding the massive complexity of NP-Hard 3D bin-packing while remaining deterministic.

Orientation: Every product is laid flat on its largest face (Largest dimension = base length, middle = base width, smallest = stacking height).
Stacking: All products are stacked vertically in a single column.
Combined Bounding Box: The algorithm calculates the maximum required length, maximum required width, and the total sum of heights.
Rotation & Fitting: The algorithm generates all unique 3D permutations of the Combined Bounding Box and checks if any permutation fits inside the physical shipping box.
Selection: Valid boxes are sorted by unused_space (ascending), then by cost (ascending).
Assumptions & Limitations
Assumption: Products are stacked vertically in a single column and placed on their largest face.
Assumption: Products are not arranged side-by-side.
Limitation: Because this is a simplified bounding-box heuristic and not a full 3D packing engine, it may reject a box that could technically accommodate the products if they were arranged in a more complex side-by-side configuration.
